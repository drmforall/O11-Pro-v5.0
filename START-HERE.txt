O11 PRO v5.0 | LINUX x86-64
==========================

1. Open README.html for the illustrated O11 Pro v5.0 release guide.
2. Read RELEASE-NOTES.md for requirements and verification limits.
3. Extract the ENTIRE archive before installation.
4. On Ubuntu/Debian, install prerequisites:
     sudo apt install python3 ffmpeg
5. From this extracted folder, run:
     sudo bash install.sh
6. Choose your admin username, password and an available port.
7. Open http://localhost:YOUR_PORT/login

No default credentials are included. Existing installations are not overwritten.
The installer creates a local-only systemd service named o11v5.
